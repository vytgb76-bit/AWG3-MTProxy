# Подготовка публичного репозитория

Этот файл содержит контрольный список перед размещением исходного кода на GitHub.

## Состав публикации

В корень репозитория помещаются `README.md`, `install.sh`, `uninstall.sh`, `euag3ctl.py`, `.gitignore`, `.gitattributes`, `PUBLISHING.md` и каталог `tests/`.

В публичный репозиторий **не** помещаются рабочие конфигурации VPN, ключи и секреты MTProxyL, журналы диагностики, снимки состояния системы, резервные копии и созданные при выполнении файлы `/var/lib/euag3guard/`.

`README.md` и тесты используют примеры из частных сетей и документальных диапазонов IPv4. При публикации не заменяйте эти примеры собственными публичными адресами.

## Проверка перед коммитом

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile euag3ctl.py
bash -n install.sh uninstall.sh

git status --short
# После git add проверьте состав индекса:
git diff --cached --name-only
```

Проверьте все добавляемые файлы на учётные данные, реальные IP, приватные домены и служебные журналы. `.gitignore` не защищает файлы, которые добавлены принудительно или уже попали в историю Git.

## Метаданные Git и GitHub

Публичная история коммитов показывает имя и email автора и коммитера. Проверьте настройки Git до первого коммита:

```bash
git config --show-origin --get user.name
git config --show-origin --get user.email
```

При желании используйте предоставленный GitHub адрес `noreply` и настройки приватности email. Имя профиля, URL репозитория, история операций, прикреплённые релизы и загруженные файлы — отдельные источники информации о владельце. Проверка исходников не обеспечивает анонимность аккаунта.

## Права на использование

В комплекте намеренно нет файла `LICENSE`: вариант лицензирования выбирает владелец проекта. Публичная доступность репозитория сама по себе не равна разрешению на любое повторное использование кода.

## Перед каждым релизом

Повторите проверки и убедитесь, что архив релиза сформирован из выбранных исходников, а не из каталога рабочего сервера. Не включайте необработанные выводы `docker inspect`, `ip addr`, `iptables-save`, `journalctl` и файлы клиента AWG.
